# Declaration OF AI Use

โครงงานนี้ได้นำปัญญาประดิษฐ์ ได้แก่ ChatGPT (GPT-4o) Claude Ai มาใช้ในขั้นตอนดังต่อไปนี้


(1) ขั้นตอนการออกแบบฟอร์มรายงานผู้ขับขี่ของผู้โดยสาร
    โดยใช้เพื่อให้คำแนะนำในการพัฒนาซอร์สโค้ดและ ปรับปรุงเพื่อให้โครงสร้างของซอร์สโค้ดไม่ให้ซับซ้อนเกินไป อีกทั้งให้ช่วยแนะแนวทางในการเขียนฟอร์มรายงานให้ภาษาเป็นทางการมากขึ้น
    
(2) ขั้นตอนการออกแบบหน้าการจัดการรายงานฝั่งแอดมิน
    โดยใช้เพื่อขอคำแนะนำในการพัฒนาโค้ดสำหรับการแสดงผลข้อมูลรายงาน ตลอดจนการจัดรูปแบบการแสดงผลให้มีความถูกต้อง เป็นระเบียบ และเข้าใจง่าย
    
(3) ขั้นตอนการรับส่ง API ในฝั่ง backend และ frontend
    โดยใช้เพื่อให้คำแนะนำในการรับส่ง API เพื่อรองรับการอัปโหลดรูปภาพผ่านระบบ Cloudinary รวมถึงการปรับปรุงซอร์สโค้ดให้โครงสร้างไม่ซับซ้อนเกินไป
   
(4) การใช้ในปรับ backend ให้ตรงกับการต้องการ
     โดยใช้ในการแก้ไขในบ้างส่วนของ backend เพื่อให้รองรับกับความต้องการของระบบที่กำลังพัฒนา
     
(5)ช่วยในการเขียน  Change Log
   โดยใช้ในการจัดรูปแบบการเขียน Change Log และตรวจข้อมูลที่ตกหล่นไป
   
(6)ช่วยในการเขียน User Manual
   โดยใช้ในการจัดรูปแบบตัวอักษรให้อ่านง่ายบน .md file และตรวจสอบคำที่ใช้เขียนอธิบาย เพื่อนำไปปรับปรุงวิธีเขียนคู่มือการใช้งาน

(7) สนับสนุนการจัดทำการทดสอบ API และ UAT (User Acceptance Testing)
    โดยช่วยออกแบบและปรับปรุงชุดทดสอบ (Test Cases) ให้มีความครอบคลุม พร้อมทั้งให้คำแนะนำเพื่อเพิ่มประสิทธิภาพในการทดสอบระบบโดยรวม

โดยข้าพเจ้าได้ตรวจสอบความถูกต้อง แก้ไข และปรับปรุงเนื้อหาให้สอดคล้องกับการพัฒนาระบบจริงด้วยตนเองเรียบร้อยแล้ว
