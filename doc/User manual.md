# User Manual

## 1. เมนูการจัดการรายงานคนขับของผู้โดยสาร (กรณีเป็นผู้ดูแลระบบ)

ผู้ดูแลระบบสามารถเข้าถึงเมนูการจัดการการรายงานเพื่อดูรายการ **รายงานทั้งหมด** ที่ถูกเพิ่มเข้ามาในระบบ โดยในแต่ละแถวของตารางจะแสดงข้อมูลพื้นฐาน ได้แก่  
- ชื่อผู้รายงาน  
- ชื่อผู้ถูกรายงาน  
- ประเภทการรายงาน  
- รายงานจากผู้โยสารหรือผู้ขับ
- วันที่แจ้งรายงาน  
- สถานะการดำเนินการ  

ผู้ดูแลระบบสามารถ **กรองข้อมูลตามสถานะการรายงาน** ได้ตามต้องการ นอกจากนี้ยังมีปุ่มสำหรับ  
- ดูรายละเอียดของรายงาน  
- ลบข้อมูลการรายงานของผู้โดยสารออกจากระบบได้โดยตรง  

![หน้ารายการรายงานคนขับ](./images/Admin_report/Admin_Report_Management.png)

---

## 1.1 หน้ารายละเอียดการรายงานคนขับ

เมื่อผู้ดูแลระบบกดปุ่ม **“รายละเอียด”** หรือปุ่มไอคอนรูปดวงตา ระบบจะแสดงหน้าสำหรับดูรายละเอียดของรายงานที่เลือก โดยแสดงข้อมูลดังต่อไปนี้

### 1.1.1 ข้อมูลผู้แจ้งรายงานและข้อมูลผู้ถูกรายงาน
ระบบจะแสดงข้อมูลของผู้แจ้งรายงานและผู้ถูกรายงานทั้งหมด เพื่อให้ผู้ดูแลระบบใช้ประกอบการพิจารณา
แสดงข้อมูลของผู้ถูกรายงาน ได้แก่  
- ชื่อและนามสกุล  
- อีเมล  
- ชื่อผู้ใช้  
- หมายเลขโทรศัพท์  

### 1.1.2 รายละเอียดการรายงาน
ในส่วนนี้จะแสดงข้อมูลที่ผู้ใช้กรอกผ่านฟอร์มรายงาน ได้แก่  
- ประเภทของการรายงาน เช่น พูดจาไม่สุภาพ ผู้โดยสารพยายามรบกวนการขับขี่
- รายละเอียดเพิ่มเติมจากผู้รายงาน  
- รูปภาพ วิดีโอและคลิปเสียงประกอบการรายงาน  
- วันและเวลาที่แจ้งรายงาน  

![หน้ารายละเอียดการรายงาน](./images/Admin_report/Admin_Report_Detail.png)

---

## 1.3 การดำเนินการของผู้ดูแลระบบ

หลังจากผู้ดูแลระบบตรวจสอบข้อมูลการรายงาน หากพบว่าข้อมูลไม่ถูกต้องหรือไม่เรียบร้อย  
ผู้ดูแลระบบสามารถ **ส่งการแจ้งเตือนไปยังผู้ใช้** เพื่อแจ้งผลการตรวจสอบได้
โดยหากผู้รายงานรายงานในหัวข้อด้านความปลอดภัย ด้านพฤติกรรมคนขับ/ผู้โดยสาร สถานะจะแบ่งได้เป็น 4 สถานะ
- รอดำเนินการ
- กำลังดำเนินการ
- ตักเตือนและลงโทษแล้ว
- ไม่พบความผิด
![ปุ่มอัปเดตสถานะการดำเนินการรายงานของแอดมิน](./images/Admin_report/Behavior_Safety.png/admin-report-status.png)

หากผู้รายงานในหัวข้อรายงานการแจ้งของหาย / ของตกหล่น สถานะจะแบ่งได้เป็น 4 สถานะ
- รอดำเนินการ
- อยู่ระหว่างการติดต่อ
- แจ้งไปที่ผู้โดยสารเรียบร้อย
- ไม่พบของ
![ปุ่มอัปเดตสถานะการดำเนินการรายงานของแอดมิน](./images/Admin_report/Lost_Found_status.png)

หากผู้รายงานปัญหาเกี่ยวกับยานพาหนะ และ ปัญหาเกี่ยวกับความเสียหายต่อรถและทรัพย์สิน
- รอการดำเนินการ
- อยู่ระหว่างสอบสวน
- แจ้งให้แก้ไขแล้ว
- ไม่พบความผิด
![ปุ่มอัปเดตสถานะการดำเนินการรายงานของแอดมิน](./images/Admin_report/Vehicle_status.png)

หากผู้รายงานแจ้งปัญหาอื่น ๆ สถานะจะแบ่งได้เป็น 4 สถานะ
- รอดำเนินการ
- กำลังดำเนินการ
- ดำเนินการเสร็จสิ้น
- ไม่พบความผิด
![ปุ่มอัปเดตสถานะการดำเนินการรายงานของแอดมิน](./images/Admin_report/Othet_status.png)

## 2. เมนูการเดินทางของฉัน (เมื่อต้องการรายงานผู้ขับขี่)

ผู้โดยสารสามารถดูรายการเดินทางที่ได้จองไว้ทั้งหมดได้ในเมนู **“การเดินทางของฉัน”**  
ระบบจะแสดงข้อมูลเส้นทางที่จอง รวมถึงรายละเอียดผู้ขับขี่ วันที่ เวลา ราคา และแผนที่เส้นทาง  
เมื่อได้รับการยืนยันจากผู้ขับขี่แล้ว ผู้โดยสารจะสามารถกดปุ่ม **รายงานปัญหา** ได้

![หน้าการเดินทางของฉันที่มีปุ่มรายงานผู้ขับขี่](./images/Passenger_report/MyTrippage_report_button.png)

---

### 2.1 หน้าหมวดหมู่เลือกหัวข้อรายงานผู้ขับขี่

เมื่อผู้โดยสารกดปุ่ม **รายงานผู้ขับขี่** ระบบจะแสดงหน้าเลือกหมวดหมู่รายงานผู้ขับขี่  
โดยผู้โดยสารสามารถเลือกประเภทการรายงานได้ ดังนี้

- แจ้งปัญหาเกี่ยวกับรถ
หลังจากกดเข้าหัวข้อนี้จะแสดงหัวข้อ ดังรูปนี้

- แจ้งของหาย / ของตกหล่น
หลังจากกดเข้าหัวข้อนี้จะแสดงหัวข้อ ดังรูปนี้

### 2.2 การแจ้งเตือนหลังส่งฟอร์มรายงาน

เมื่อผู้แจ้งรายงานกดปุ่ม **ยืนยัน** ระบบจะแสดงข้อความแจ้งเตือนที่ **ไอคอนรูปกระดิ่ง** และหากผู้ดูแลทำการเปลี่ยนสถานะจะทำการแจ้งเตือน ดังรูป

## 4. ประวัติการรายงานของฉัน
สามารถกดเข้าดูประวัติการรายงานโดยกดผ่านNotification หรือ เลือกเมนูบัญชีของฉันและเลือก**ประวัติการรายงานของฉัน** โดยจะแสดง หัวข้อการรายงาน ชื่อผู้ถูกรายงาน อีเมล เบอร์โทรศัพท์ของผู้ถูกรายงาน วันที่แจ้ง วันที่อัปเดตสถานะ รายละเอียดหมวดหมู่ หลักฐานที่แนบ ดังรูป
